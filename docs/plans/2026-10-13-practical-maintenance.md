# V1.8 实战连接与定期维护

用户授权：每周核对官方能力并做有价值的小更新；每三周自行制定策略、实操一次较大迭代；发布走 majia-ota。较大迭代不等于破坏兼容，因此本轮使用 1.8.0。

本轮发现：本机原先没有 Hosted ChatCut 注册；当前官方核心指令与旧快照哈希一致，但仓库提交已变化，导入脚本变化不在旧九文件检查范围内。官方网页版本与插件源码版本分别记录。

## 实施

1. 增加只读 `live:probe`。使用已有 mcporter OAuth，不读取或导出凭据；只连接官方 Hosted 地址，获取工具清单并调用 `list_projects` 确认登录。只输出计数、能力和工具合同指纹，不输出项目 ID、名称、URL、字幕。接入成功不等于媒体、编辑、试听或整条稳剪通过。
2. 扩展官方检查：验证实际 checkout 提交，监测整个 Hosted Skill 目录及 MCP 配置，区分新增、删除和内容变化。新增监测基线只是文件指纹，不冒称所有内容已审查；变化后必须具体审阅，不能自动接受。
3. 在独立真实项目实操：创建、结构回读、标记写入与清理、编辑器/合成画面验证。原项目不写入。无真实口播样本和人耳试听时保留完整稳剪 UNVERIFIED。
4. 更新入口、维护周期与实操记录，按仓库门禁和 majia-ota 验证、提交、推送与准确 SHA 回读；本机同步先预演并回读。

## 验证重点

工具返回错误、401、无工具和不完整清单不算接入成功；工具输出含项目私密信息时不外泄；工具参数及语义变化让合同指纹失效；官方未审查目录变化不能漏检；回读和画面不得互相替代。定时任务已创建，每周二运行；以 2026-10-13 为首轮，2026-11-03 为下一轮较大迭代。
