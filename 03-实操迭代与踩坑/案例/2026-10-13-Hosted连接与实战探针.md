# Hosted 连接、真实写入与监测范围

## 事实

本轮本机最初没有注册 Hosted ChatCut。使用当前官方基础指引注册官方 MCP，用户完成 OAuth；登录回执之后另行读取工具清单并调用账号项目读取。实际发现 62 个工具。Codex 与外部 MCP 客户端的授权缓存分别确认，未把一个客户端的 OAuth 回执冒称另一个客户端可调用。

在独立空白测试项目中，以 30fps、1920×1080 创建时间线。创建帧 0 的临时标记，随后按同一时间线回读；编辑器可见该标记。收工前删除，工具确认已删除。

使用 Library 已有标题模板，复制为独立测试时间线内容。结构回读确认一个 150 帧的 MG 实例；原有空轨与新增模板轨分别识别。通过 `preview_timeline` 获取编辑器合成联系图，实际检查 0、60、120 帧；再检查 0、1、2、60 帧。

60/120 帧能看到标题和副标题。0 帧为黑，1/2 帧出现角部入场画面。这只能记录为模板当前开头表现；没有先确定模板的创作意图，不判为宿主 bug，也不声称首帧没有黑场。标题停留帧正确不代表整个动画或口播质量通过。

## 工程改动与采用

旧官方监测只覆盖九个已审查文件。当前官方提交改变但这些文件哈希未变，旧检查仍返回通过；导入 helper 变化可能漏检。因此新增提交核对与 Hosted 包文件指纹。本轮采集 46 个监测文件指纹，`watchedFiles` 明确不同于 `reviewedFiles`。不复制官方实现或 Skill 原文。

新增 `live:probe` 实际读取官方工具清单和账号项目。输出只含工具数量、项目数量和合同指纹，不含项目名称、ID、URL、字幕或凭据。它不会写时间线，不把连接成功升级为媒体、剪辑、试听或生产稳定。

本机 OTA 同步元数据曾被 JSON release gate 当成无合同公开文件。明确仅排除根目录 `.skill-sync.json`，保留原文件；子目录同名文件仍会验证。同步 metadata 与 `.DS_Store` 不提交。

## 验证范围

- E1：工具清单、账号项目读取、测试项目结构、标记创建/回读/删除、模板实例与轨道回读。
- E2：编辑器可见测试标记；已检查指定时间点的编辑器合成联系图。
- 未验证：真实口播清理、字幕分页、音频切口、人耳试听、导出文件、超时恢复与手工修改保护的真实覆盖。
- 本案例不计为八类生产口播 canary，不提升 `stableClaimEligible`。
- 全量发布检查：416 个测试通过，1 个现有跳过，0 失败；Schema、运行合同、规则、恢复模拟、文档、资产、对比度、公开内容及版本检查通过。

公开版不含真实项目、时间线、资产、标记 ID、签名 URL、人物素材、账号信息或本机绝对路径。私有工具回执及图片留在本机维护工作目录。
