# 环境与文字修改

先明确当前项目在哪里，再决定执行方式。先明确要改哪一层，再决定文字操作。官方源码快照是维护依据；当次工具说明才是执行依据。

## 当前环境

Hosted/Web 使用当前插件的 `chatcut-plugin-basics` 和按需官方 Skills。Desktop 使用签名应用同步的指令与当前 `chatcut_desktop*` 工具；托管 Desktop Agent 使用项目绑定指令。不要把 hosted Skill 强塞进 Desktop，也不要因缺少工具而静默改走另一环境。两种环境都存在且无法确定目标时，只询问目标项目所在环境。

`preflight` 是只读的本地合同检查，不连接账号、不安装应用、不上传素材、不编辑项目。Agent 从当前会话读取 Skill 来源与工具 schema，再在本机形成 `session-observation.schema.json` 定义的记录。`capabilities` 是从当次工具定义确认的业务能力标签，不是猜测的工具名。记录必须包含采集时间、失效时间和工具定义哈希，有效期最多 24 小时；会话、工具定义或项目环境改变后立即重读，不等到过期。

```bash
npm run preflight -- --session <current-session.json> --json
npm run run -- --intent "只改字幕，别剪原声" --session <current-session.json> --dry-run --json
```

没有记录、来源不匹配、所需能力缺失、过期或模拟记录会返回明确缺口。`preflight` 不满足时退出非零。普通 `run` 仍可保存本地需求草稿，但下一步是补齐环境合同，不能据此开始写入。`contractReady=true` 只表示提供的会话记录通过检查，不能证明账号登录、项目访问、实际写入、画面或听感；运行清单的真实能力证据仍保持独立。

## 四种文字目标

| 用户想做什么 | 正确对象 | 保持与验证 |
| --- | --- | --- |
| 只改字幕、隐藏一张字幕卡 | 字幕显示卡与字幕程序 | 不改原声、不剪源视频；回读当前卡片与合成画面 |
| 原声没错，只是 ASR 听错 | 源转写 | 根据原声纠正；不生成替换语音；阶段结束时按官方指令刷新依赖字幕 |
| 剪掉这句口播 | Script 驱动的内容剪辑 | 重建完整语义单元，再按风险审批；检查所有相关轨道 |
| 实际说错了，替换局部原声 | 明确批准的局部语音替换 | 高风险独立审批；确认文字、区域、说话人声音与克隆权限，保留原画面和后续时序，试听接缝 |

“删掉这里的文字”或同时涉及多层的模糊请求先澄清，不默认变成剪切。保守识别只覆盖明确表达；未命中的表述仍需 Agent 根据实际源声、用户目标和当前官方指令判断。

只改字幕、只修转写和原声替换都会关闭默认口播清理与音频平滑，避免顺带重剪。读到 `textEdit.target=clarify` 时不得写入。请求某项能力只是加载对应指令，不能替代审批。

## 字幕身份与旧经验

当前官方字幕操作以可恢复字幕卡/程序为主。显示文字、源转写、语音内容不是同一个对象。字幕重分段会重建卡片身份；完成一个阶段后重新读取卡片、修订号和翻译覆盖，再写下一批，旧卡片引用与旧样片证据不得复用。样式预览只代表候选，选择提交并回读后才代表项目状态。

历史词级 override、固定字数容量和一帧 guard 只用于命中旧故障的修复候选。不要在新项目里默认复刻。原始案例保留为事实证据；本版不宣称旧字幕、同步或子帧问题已被官方彻底修复。

## 下次官方更新

```bash
# 校验已记录的来源快照，不联网
npm run check:official
# 先从官方 GitHub 取得只读 checkout，再比较版本、Skill 清单与已审查文件
npm run check:official -- --checkout <official-checkout> --json
```

命令只对照所提供的 checkout，不替你获取远端最新版。版本、清单或已审查文件哈希变化会报 drift；重读官方文档和相关历史案例后，再决定是否改变本包。不能因为生成模型变多就开启默认生成、导出或发布。真实 ChatCut 端到端仍为 `UNVERIFIED`。
