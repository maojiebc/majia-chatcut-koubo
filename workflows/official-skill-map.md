# ChatCut 官方能力分工

本包是 ChatCut 官方能力之上的编排与实战默认层，不是另一套视频编辑器，也不复制官方教程、工具参数或内部标识获取方法。

运行时以当前 ChatCut 官方技能（Skill）、当前工具说明和实时参数定义为准。本包只保存相对稳定的产品合同：用户意图、剪辑配置、风险分级、阶段顺序、样片审批、恢复规则、验证状态和交付报告。

## 基础加载顺序

非机械小修的口播任务先读取：

1. `chatcut-plugin-basics`：确认项目模型、项目定位和当前工具合同；
2. `talking-head-guide`：使用官方口播清理方法；
3. `transcription`：任务涉及转写或字幕时读取；
4. `verification`：使用官方结构回读和实际合成画面验证。

其他能力只在任务需要且用户已经授权时读取。

## 分工地图

| 官方技能 | 官方负责 | 本包负责的增量 |
|---|---|---|
| `chatcut-plugin-basics` | 项目、素材、轨道、时间线和当前工具合同 | 一键流程、运行记录、用户授权范围、阶段说明 |
| `talking-head-guide` | 口误、重说、停顿、字幕和口播基础方法 | 个人默认密度、风险分级、代表样片和受保护设计 |
| `transcription` | 转写及字幕相关操作 | 术语表、精校稿优先级、数字/专名/否定保护 |
| `verification` | 结构回读和真实合成画面检查 | 证据分级、代表窗口和最终交付报告 |
| `asset-import` | 导入本地或附件素材 | 主素材识别、来源清单和重复导入防护 |
| `multicam-sync` | 多机位同步 | 单一可听对白、同步后检查和双音轨防重 |
| `music` | 音乐检索、生成、放置和编辑 | 默认关闭、对白优先、单独审批和音量约束 |
| `create-motion-graphics` | 创建和放置动态图形 | 判断何时不该添加、主题选择和样片审批 |
| `shader-gen` | 生成特殊画面效果 | 仅在普通裁切或遮罩无法完成时使用，并保留回退 |
| `video-gen` | 生成视频素材 | 默认关闭；只在明确授权后作为候选，不能冒充证据 |
| `voice` | 语音相关能力 | 默认保留口播原声，不自动换声 |
| `export` | 导出和任务追踪 | 单独取得授权、明确规格、检查最终文件 |
| `known-errors` | 官方已知错误和恢复建议 | 现场失败记录、三轮止损和交接说明 |
| `product-help` | ChatCut 产品帮助 | 只在流程中精准路由，不复制产品手册 |
| `widget-forms` | 一次性结构化询问 | 只询问无法从项目读取、且会改变结果的信息 |

## 路由原则

- 用户没有附素材时，先查看项目资产库，不立刻要求重新上传。
- 已存在的素材不重复导入。
- 主体口播尚未确定前，不制作正式字幕、音乐、动态图形或补充画面。
- 音乐、动态图形、补充画面、生成素材和导出均为按需能力，默认关闭。
- 导出不等于发布；本包不自动发布用户视频。
- 登录或工具不可用时，按官方恢复说明处理，不自行启动替代服务或制作替代编辑器。

## 不保存易漂移内容

本仓库不长期写死当前工具名、参数、内部对象标识获取方式或未绑定版本的宿主观察。官方能力发生变化时，先读取当前定义，再决定本次运行是否可继续；能力缺失就明确受阻，不静默换成低质量路线。

## 当前证据边界

真实 ChatCut 端到端状态目前为未验证（UNVERIFIED）。离线路由、模拟会话和文档合同不能证明真实项目已经成功写入、渲染、试听或恢复。每次交付必须依据当次项目的结构回读、合成画面、声音证据和用户确认分别报告状态。
